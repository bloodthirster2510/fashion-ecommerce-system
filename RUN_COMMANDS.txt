FASHION E-COMMERCE - LENH CAI DAT VA CHAY DU AN
================================================

Yeu cau:
- Node.js va npm
- MongoDB dang chay
- Moi khoi lenh nen chay trong mot terminal rieng


1. BACKEND
----------

cd D:\LV\fashionshop\fashion-ecommerce-system\backend

# Cai dependency (chi can lan dau hoac khi package.json thay doi)
npm install

# Tao file moi truong lan dau
Copy-Item .env.example .env

# Chay development
npm run dev

# Du lieu mau (chi chay khi can seed lai database)
npm run seed

# Build va chay production
npm run build
npm start

# Test
npm test
npm run test:e2e

# VNPAY tunnel (tuy chon, mo terminal rieng)
npm run dev:vnpay


2. WEB FRONTEND
---------------

cd D:\LV\fashionshop\fashion-ecommerce-system\web_frontend

# Cai dependency
npm install

# Chay development
npm run dev

# Build production
npm run build

# Xem thu ban production da build
npm run preview

# Kiem tra code
npm run lint

# E2E test
npm run test:e2e


3. MOBILE (EXPO)
----------------

cd D:\LV\fashionshop\fashion-ecommerce-system\mobile

# Cai dependency
npm install

# Tao file moi truong lan dau
Copy-Item .env.example .env

# Chay bang Development Build (khuyen dung, ho tro push notification)
npm run start:dev

# Chay bang Expo Go (khong ho tro remote push notification tren Android)
npm run start:go

# Build/cai truc tiep len Android emulator hoac dien thoai ket noi USB
npm run android

# Chay phien ban web cua mobile
npm run web


4. EAS DEVELOPMENT BUILD (LAN DAU)
---------------------------------

cd D:\LV\fashionshop\fashion-ecommerce-system\mobile

npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --platform android --profile development

# Tai APK development ve dien thoai, cai dat, sau do chay Metro:
npm run start:dev


5. EAS PRODUCTION BUILD
-----------------------

cd D:\LV\fashionshop\fashion-ecommerce-system\mobile

# Android App Bundle de dua len Google Play
npx eas-cli@latest build --platform android --profile production


LUU Y
-----

- Khi chay tren dien thoai that, EXPO_PUBLIC_API_URL trong mobile\.env phai dung
  dia chi IP LAN cua may tinh, vi du: http://192.168.1.10:5000/api
- Dien thoai va may tinh can chung mang Wi-Fi; firewall phai cho phep cong backend.
- Khong chay npm install dong thoi voi Metro/Expo neu Windows bao loi EPERM.
- Thu tu chay thong thuong: MongoDB -> backend -> web frontend -> mobile.
